# Trainings-App

Persönliche Trainings- und Essens-App (React, eine Datei `index.html`), gehostet mit GitHub Pages,
Daten zusätzlich im Google Sheet über Google Apps Script.

- Bauen: `npm install` und `npm run build`
- Lokal ansehen: `npm run serve` → http://localhost:8787
- Danach `index.html` und `sw.js` committen.

Alle Details für die Weiterentwicklung stehen in `CLAUDE.md`.
